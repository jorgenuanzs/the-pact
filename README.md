# The Pact

Pact es un plano de control para proyectos en los que personas y agentes de IA comparten conocimiento, coordinan trabajo y realizan acciones verificables sobre código, infraestructura y otros recursos.

## Estado

El proyecto se encuentra en definición arquitectónica y preparación de su primer recorrido implementable.

## Primer objetivo

Demostrar que dos agentes pueden trabajar sobre el mismo repositorio, compartir estado útil y coordinar cambios sin tener que intercambiar sus conversaciones.
